# Копилка с красивыми числами

Прототип для хакатона СберKids «Создаем эмоции», трек **A · Приколы**.

Когда в копилке ребёнка оказывается «красивое» число, цифры оживают. Оформление и правила меняются из конфига, без релиза.

| Число | Пример | Оформление |
|---|---|---|
| Как купюра | 100, 500, 1 000, 2 000, 5 000 | цвет номинала и гильош-узор (без изображения банкнот) |
| Одинаковые цифры | 777, 2 222, 7 777 | переливающийся градиент |
| Лесенка | 123, 1 234, 4 321 | цифры-кубики для счёта |
| Зеркальное | 1 221, 12 321 | парные цифры одного цвета и линия симметрии |
| Повторяющиеся пары | 1 212, 2 020 | переливающийся градиент |
| Круглое | 300, 2 500, 10 000 | пульсирующие нули |

Кроме красивых чисел, эффект срабатывает на **пополнение** (монетка падает, сумма досчитывается) и на **этапы цели** (25 / 50 / 75 / 100 %). Если потрясти телефон на экране копилки, монетки звенят, а красивое число показывает эффект ещё раз.

## Как работает

- **Оформление цифр на выбор.** На экране копилки есть кнопка «Цифры»: ребёнок выбирает, как выглядит его сумма — «Авто» (своё оформление у каждого красивого числа), «Строгий», «Купюра», «Кубики», «Переливы», «Зеркало», «Зелёный». Выбор хранится только на устройстве, а список оформлений приходит из конфига (`themes`), так что новое, например новогоднее, добавляется без релиза.

- **Автоматически** показывается только тихий блик и подпись «Нажми на цифры». Полный эффект запускается **по тапу**, **встряхиванию** или после **пополнения**: разноцветное конфетти, серпантин, салют или дождь из монет, радужная волна и вспышка за суммой, цифры перекатываются и по очереди подпрыгивают, плашка с радужной рамкой, вибрация, звук. Сами цифры в покое остаются сдержанными, праздник ощущается только в момент эффекта.
- Вариант анимации каждый раз выбирается из списка в конфиге, а сезонные частицы (осенью листья, зимой снег) добавляются по календарю. Поэтому повторный показ не одинаковый.

## Соответствие брифу

| Требование | Как выполнено |
|---|---|
| Слой поверх, не блокирует сценарии | `pointer-events: none`, ввод не перехватывается ни на миг |
| Не перекрывать оплату и переводы | на экранах `data-overlay="forbidden"` эффект не запускается, а запущенный гаснет при переходе |
| Не блокировать дольше эффекта | длительность ограничена `maxEffectMs` (по умолчанию 1,8 с) |
| Не замедлять запуск и главный экран | конфиг грузится после первой отрисовки, до загрузки эффекты просто выключены |
| Битый конфиг не ломает приложение | невалидные правила отбрасываются по одному, сломанный JSON выключает эффекты; это покрыто тестами |
| Без бэкенда | JSON по ключу CMS и статика с CDN, состояние только на устройстве |
| Персональные данные не уходят | сумма проверяется локально, сеть нужна только для скачивания конфига |
| Без лотерей и тёмных паттернов | нет случайных наград, ставок, таймеров и «джекпот-777»; прикол поощряет копить, а не тратить |
| Без новых разрешений | акселерометр в нативных приложениях разрешения не требует |
| Звук не включается сам | выключен по умолчанию, есть кнопка 🔇/🔊 |
| Обе платформы | только стилизация текста, Lottie, haptic и акселерометр; всё это есть на Android и iOS |
| Вес ≤ 6 МБ, 60 fps | весь прототип занимает около 180 КБ, частиц не больше 240, один canvas; замер — около 60 кадров/с во время эффекта |

## Управление контентом без релиза

Всё задаётся в `config/effects.json`, который в приложении лежит по ключу CMS:

- `rules`: какие числа считать красивыми (`exact`, `repdigit`, `sequence`, `palindrome`, `round`, `regex`), их порядок как приоритет, текст плашки, список вариантов анимации;
- `styles`: цвета и тип оформления (в приложении ещё ссылка на Lottie и шрифт на CDN);
- `milestones`: этапы цели и тексты;
- `seasons`: сезонные частицы по датам;
- `autoMode`, `autoOnTopup`, `maxEffectMs`, `enabled`: поведение и общий выключатель.

Как показать это на защите:

- **Редактор в демо-панели** (⚙︎ в правом нижнем углу), раздел «Красивые числа — правка без релиза»: любой тип числа включается и выключается переключателем. Можно добавить своё число (например, 2026) с оформлением и текстом плашки, и копилка сразу покажет, как это увидит ребёнок. Так работал бы экран контент-менеджера в CMS.
- **«Для разработчика»**: тот же конфиг сырым JSON. Кнопка «Сломать конфиг» показывает, что приложение продолжает работать.
- **По-настоящему без релиза**: поправь `config/effects.json` прямо на GitHub (карандаш → Commit). Через пару минут открытые телефоны получат новый конфиг при следующем входе, код при этом не меняется.

## Работа без интернета

Прототип работает офлайн. При первом открытии ссылки service worker (`sw.js`) сохраняет все файлы на телефоне. Дальше можно включить авиарежим и перезагрузить страницу: интерфейс, эффекты и конфиг продолжат работать. Конфиг загружается по схеме «сеть сначала, иначе кэш»: онлайн берётся свежий, офлайн — последний сохранённый. Готовность показана внизу демо-панели: «✓ Офлайн-режим готов».

Все шрифты системные, иконки встроены в страницу, внешних запросов нет. Все файлы загружаются по схеме «сеть сначала, иначе кэш», поэтому правки из репозитория доходят до телефонов при следующем открытии с интернетом. `VERSION` в `sw.js` трогать не нужно.

## Запуск

```bash
# любой статический сервер в папке проекта
python3 -m http.server 8000
# телефон в той же сети: http://<IP ноутбука>:8000
```

Ещё проще выложить репозиторий на **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root) и открыть ссылку на телефоне. Прототип работает и как открытый файл `index.html`: в этом случае подхватывается встроенная копия конфига.

> Встряхивание в браузере iPhone требует разрешения (Safari спросит при первом тапе по сумме). В нативном приложении разрешение не нужно.

## Структура

```
index.html               экраны-заглушки: главная, копилка, пополнение, оплата + демо-панель
css/app.css              оформление, в том числе стили красивых чисел (data-pattern)
js/engine.js             правила: классификация суммы, этапы цели, сезоны, оформления, валидация конфига
js/overlay.js            слой эффектов: частицы на canvas, плашки, вибрация, звук
js/app.js                склейка: навигация, пополнение, загрузка конфига, демо-панель
js/default-config.js     встроенная копия конфига (генерируется)
sw.js                    офлайн-режим: кэш всех файлов на телефоне
manifest.webmanifest     установка «на экран Домой», иконки в icons/
config/effects.json      конфиг, который в приложении лежит по ключу CMS
tests/engine.test.js     тесты движка
tools/build-default.js   пересборка default-config.js
```

```bash
node tests/engine.test.js        # тесты движка (18)
python3 tests/e2e.py             # сквозные тесты в браузере: ~200 проверок (нужен запущенный http.server 8765 и playwright)
node tools/build-default.js      # после правки config/effects.json
```

## Путь внедрения в СберKids

| Часть | Android | iOS |
|---|---|---|
| Правила (`engine.js`, ~150 строк) | Kotlin, чистая функция | Swift, чистая функция |
| Стили цифр | Compose `Text` + `Brush` / `drawBehind` | SwiftUI `Text` + `foregroundStyle` / `background` |
| Частицы | Lottie (уже в стеке) | Lottie (уже в стеке) |
| Тактильность и звук | уже есть в приложении | уже есть в приложении |
| Встряхивание | `SensorManager` | `CoreMotion` |
| Конфиг | новый ключ в CMS + кэш | новый ключ в CMS + кэш |

Новых зависимостей, эндпоинтов и разрешений нет. Работа сводится к одному компоненту суммы на экране копилки, на каждой платформе отдельно.
